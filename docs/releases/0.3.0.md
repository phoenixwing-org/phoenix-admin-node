# Phoenix Admin Node 0.3.0 发布说明

## 发布定位

`0.3.0` 汇总 Phoenix Admin Host 近期的插件治理能力：开发挂载健康检查、受控插件
生命周期、品牌快照、导航与字典治理、版本化 Host 基线以及 Host Files v1。

## 主要能力

- 开发挂载与正式 payload 分层校验，问题插件隔离而不拖垮 Host；
- `.phoenix.cool` 包保留、恢复、dry-run、可信备份、受控安装与数据保留卸载；
- 版本化 Host 空库基线补齐身份、文件与插件治理约束；
- Host Files v1 提供 descriptor、绑定、权限、审计及稳定插件端口；
- 工作台品牌安全快照支持 Host 默认配置与品牌插件接管、停用恢复；
- Midway 4、PostgreSQL、`synchronize=false` 与 `initialize=false` 继续作为运行边界。

## 发布边界

- 不包含任何业务插件产品源码、产品表或产品迁移；
- 不手工修改插件 ledger，不使用 ORM synchronize 代替版本化基线；
- 本地归档不创建 tag、不 push，由发布负责人完成远端发布。
